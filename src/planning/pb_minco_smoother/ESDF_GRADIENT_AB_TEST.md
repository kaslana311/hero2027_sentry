# ESDF 切向梯度剔除开关（2026-11-04）

## 目的和范围

只验证一个变量：MINCO 的 ESDF 距离梯度是否先剔除当前曲线切线方向的分量。
参数为 `minco_smoother.project_esdf_gradient`，布尔类型，默认 `true`。
第一轮形状优化、第二轮运动学优化共用一次平滑开始时读取的同一个值。
运行中修改后从下一次平滑请求开始生效；已经发给 MPC 的轨迹不会被立即撤销。

此改动不改变 A*、局部重规划、DOG 滤波、地图、TF、热启动 PVA、MPC、避障权重、
安全距离、标量避障代价或时间分配。也不增加新的仿真启动参数；正常启动后修改 ROS 参数即可。
所有使用该 MINCO 插件的代价地图模式都可以测试，默认值维持旧行为。

## 开关具体控制什么

设距离梯度为 `g`，当前曲线单位切线为 `t`。

- `true`：使用旧逻辑，先计算 `g - (g·t)t`，再经过原有的梯度增强和近零回退。
- `false`：跳过这一投影，直接将 `g` 交给同一套原有的增强和近零回退。

注意：关闭的只是切向分量剔除，不是关闭 ESDF 避障，也不是取消梯度增强。
开启时若投影结果接近零，原有回退仍可能重新使用原始梯度，因此不能把它理解成
“开启后绝对没有前后方向的避障作用”。两种状态都保留软约束，不会变成硬碰撞检查。
这里的切线是采样点处**当前 MINCO 曲线的速度方向**，不是固定的车头方向或 A* 直线方向。

## 使用命令

在已 source 算法工作区的另一个终端查看当前值：

```bash
ros2 param get /red_standard_robot1/smoother_server minco_smoother.project_esdf_gradient
```

关闭剔除，测试完整方向的距离梯度：

```bash
ros2 param set /red_standard_robot1/smoother_server minco_smoother.project_esdf_gradient false
```

恢复旧行为：

```bash
ros2 param set /red_standard_robot1/smoother_server minco_smoother.project_esdf_gradient true
```

重启算法后回到默认 `true`，除非在自己的参数 YAML 中显式覆盖。

## 建议的 A/B 顺序

1. 每次从同一位置、同一朝向重新开始，使用相同目标、定位偏移、地图模式和滤波配置。
2. 先取消/结束导航，至少等 3 秒，再设置参数并核对值，最后发送目标。
   这样旧轨迹的 2 秒热启动有效期已过，避免 A/B 沿用不同历史轨迹；此开关本身不清除热启动缓存。
3. 分别测试短洞、长洞；若是要比较未过滤的洞口，必须确认实际代价地图里确实存在该洞口障碍。
4. 只看最终平滑轨迹/MPC reference 不够，最好同时记录原 A*、两阶段轨迹、位置和最终速度指令。
5. 如果测试目的是隔离 MINCO 机制，建议两组都使用 `split_local_refinement:=false`；
   如果想测现在的组合方案，则两组都保持 `true`，不要一组开一组关。

这个开关本身不会证明哪种方式一定能过洞；需要同条件实测。即使梯度更完整，非凸软约束
也没有“保证安全通行”的性质；在窄洞前停住或绕行可能正是本次实验要观察的差异。

## 验证边界

回归测试检查默认/显式开启完全一致、关闭在含切向梯度的场景改变优化结果、
无 ESDF 时两种状态完全一致。另用实际插件验证 ROS 参数切换和恢复。
这些验证不等同于 Gazebo 六个隧道的通行率测试。

实现只有两个运行时代码文件：优化器配置中新增默认开启的布尔量，并把原来的
投影条件加上该布尔判断；平滑器声明 ROS 参数并在每次请求开始时读取一次，传给两个优化器。
参数服务不直接修改正在工作的优化器，因此不会发生第一轮开启、第二轮关闭的半次切换。
